# 84 — Project progress presentation

**Executor Type:** `Workplace AI`  
**Executor:** `Google Gemini`  
**Environment:** `Google Slides`  
**Department Tags:** `Operations`, `Management & Strategy`  
**Function Tags:** `Summarization`, `Transformation`, `Generation`  
**Task:** `Project progress presentation`

---

## Goal
Prepare a stakeholder presentation that shows where the project really stands.

## Build
Cover objective, current phase, completed milestones, work in progress, next milestones, blockers, dependencies, scope changes, and decisions required.

## Emphasis
Show change since the previous reporting point when available. Give risks and delayed milestones more visual weight than routine activity.

## Output
Create a concise slide sequence with one project message and supporting evidence per slide.

## Check
Do not invent completion percentages, dates, or “green” status. Flag stale or contradictory project information.
