# 99 — Organizational request triage

**Executor Type:** `Custom Organizational AI`  
**Executor:** `Internal Agent`  
**Environment:** `Internal Workflow`  
**Department Tags:** `Finance & Administration`, `People & HR`, `Operations`  
**Function Tags:** `Classification`, `Extraction`, `Decision Support`  
**Task:** `Organizational request triage`

---

## Intake Goal
Triage an organizational request before it enters an internal workflow.

## Extract
Identify requested outcome, affected department or people, urgency, confidentiality, approvals needed, dependencies, and missing information.

## Decide
Classify the request and select the appropriate finance, HR, operations, or cross-functional route using the organization’s rules.

## Output
Return Request Summary, Category, Priority, Destination, Missing Information.

## Safety
Do not expose sensitive details unnecessarily. High-impact, ambiguous, or multi-department requests should be escalated for human review.
