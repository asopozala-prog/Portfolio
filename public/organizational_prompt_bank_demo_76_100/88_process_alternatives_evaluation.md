# 88 — Process alternatives evaluation

**Executor Type:** `General AI`  
**Executor:** `ChatGPT Workspace`  
**Environment:** `Analysis`  
**Department Tags:** `Operations`, `Management & Strategy`  
**Function Tags:** `Comparison`, `Analysis`, `Decision Support`  
**Task:** `Process alternatives evaluation`

---

## Decision Problem
Evaluate alternative process designs against the organization’s actual constraints.

## Compare
For each option assess steps, handoffs, cycle time, effort, control points, dependencies, scalability, implementation difficulty, and likely failure points.

## Choose
Explain which option best fits the stated success criteria. If the evidence is incomplete, identify the deciding information instead of forcing a winner.

## Output
Provide a comparison, trade-offs, recommendation, and implementation considerations.

## Discipline
Do not invent cost savings, capacity gains, system features, or staffing assumptions.
