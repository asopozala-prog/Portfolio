# 92 — Existing function test coverage review

**Executor Type:** `Coding / Technical AI`  
**Executor:** `GitHub Copilot`  
**Environment:** `IDE / Codebase`  
**Department Tags:** `Operations`  
**Function Tags:** `Analysis`, `Validation`, `Generation`  
**Task:** `Existing function test coverage review`

---

## Review Goal
Determine whether the selected function is tested where failure would matter.

## Inspect
Map inputs, outputs, branches, boundary conditions, side effects, exceptions, and integrations. Compare this behavior to the existing test suite.

## Prioritize
Identify missing tests by regression risk, not by percentage coverage alone. Focus on meaningful paths and failure cases.

## Output
Provide Covered Behavior, Important Gaps, and specific tests to add; generate tests if requested.

## Constraint
Do not invent expected behavior. Base assertions on code, documented requirements, or existing contracts.
