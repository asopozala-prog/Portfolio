# 85 — Shared knowledge file discovery

**Executor Type:** `Workplace AI`  
**Executor:** `Google Gemini`  
**Environment:** `Google Drive`  
**Department Tags:** `Operations`  
**Function Tags:** `Research`, `Classification`, `Extraction`  
**Task:** `Shared knowledge file discovery`

---

## Search Goal
Find the internal files that best answer the working question.

## Retrieval
Search by meaning, not filename alone. Look for current guidance, approved procedures, decision records, project documents, and subject-matter notes that directly address the topic.

## Rank
Prioritize authority, recency, and direct relevance. Keep outdated or draft material in a separate caution group.

## Output
Return a ranked shortlist with file name, why it matters, and the useful information found.

## Check
Do not present duplicates or superseded drafts as equal evidence. Flag conflicting sources.
