# 82 — Job description refinement

**Executor Type:** `Workplace AI`  
**Executor:** `Google Gemini`  
**Environment:** `Google Docs`  
**Department Tags:** `People & HR`  
**Function Tags:** `Analysis`, `Transformation`, `Generation`  
**Task:** `Job description refinement`

---

## Objective
Improve a job description before publication.

## Diagnose
Find vague responsibilities, duplicate requirements, unrealistic “must-haves,” unclear seniority, inconsistent terminology, and wording that hides what the job actually does.

## Rewrite
Clarify role purpose, main responsibilities, required versus preferred qualifications, and practical expectations. Keep the employer’s actual scope and terminology.

## Output
Return a clean job description with Role Purpose, Responsibilities, Requirements, Preferred Qualifications, Practical Information.

## Limit
Do not invent salary, benefits, duties, or qualifications. Flag unclear requirements for HR rather than deciding them yourself.
