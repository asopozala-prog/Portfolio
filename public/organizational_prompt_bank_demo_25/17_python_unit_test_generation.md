**Function Tags:** `Generation`, `Validation`  
**Task:** `Python unit-test generation`

---

Generate focused unit tests for the selected Python code.

## Goal
Increase confidence in expected behavior and important failure cases.

## Inspect
- Understand the function or module contract.
- Cover normal behavior, boundaries, and meaningful error cases.
- Reuse the project’s existing testing conventions where visible.

## Context
Use the selected code and surrounding repository context. Prefer the testing framework already used by the project.

## Output
Produce concise executable unit tests with clear test names.

## Check
Do not invent APIs or behavior not supported by the code. Avoid redundant tests and unnecessary mocking.
