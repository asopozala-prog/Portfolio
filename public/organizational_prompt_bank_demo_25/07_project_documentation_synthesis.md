# 07 — Project documentation synthesis

**Executor Type:** `Workplace AI`  
**Executor:** `Google Gemini`  
**Environment:** `Google Docs`  
**Department Tags:** `Operations`  
**Function Tags:** `Summarization`, `Transformation`  
**Task:** `Project documentation synthesis`

---

Synthesize the supplied project documentation into one clear working document.

## Goal
Create a coherent project overview from fragmented or overlapping material.

## Synthesize
- Combine repeated information without losing important distinctions.
- Organize objectives, scope, status, decisions, and next steps.
- Preserve relevant dates, owners, dependencies, and constraints.

## Context
Use the selected Google Docs material as the source.

## Output
Produce a concise project brief with clear headings and actionable next steps.

## Check
Flag contradictions, outdated statements, and information whose current status cannot be established.
