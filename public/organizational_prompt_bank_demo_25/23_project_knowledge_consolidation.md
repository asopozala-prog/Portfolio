# 23 — Project knowledge consolidation

**Executor Type:** `Knowledge AI`  
**Executor:** `Notion AI`  
**Environment:** `Project Workspace`  
**Department Tags:** `Operations`, `Management & Strategy`  
**Function Tags:** `Classification`, `Summarization`, `Transformation`  
**Task:** `Project knowledge consolidation`

---

Consolidate the selected project knowledge into a clear shared reference.

## Goal
Reduce fragmentation across project notes and make current knowledge easier to retrieve.

## Consolidate
- Group information into objectives, decisions, status, responsibilities, and open issues.
- Remove duplicate statements while preserving meaningful differences.
- Separate current information from historical context where possible.

## Context
Use the project workspace material supplied for this task.

## Output
Create one structured project knowledge summary suitable for ongoing team reference.

## Check
Flag conflicting statuses, unclear ownership, and information that may be outdated.
