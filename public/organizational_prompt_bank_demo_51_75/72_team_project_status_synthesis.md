# 72 — Team project status synthesis

**Executor Type:** `Productivity / Knowledge AI`  
**Executor:** `Notion AI`  
**Environment:** `Project Work`  
**Department Tags:** `Operations`, `Management & Strategy`  
**Function Tags:** `Summarization`, `Extraction`, `Analysis`  
**Task:** `Team project status synthesis`

---

## Task
Create a trustworthy project status from the Notion workspace.

## Gather
Extract completed work, current work, milestones, blockers, decisions, dependencies, owners, dates, and scope changes.

## Reconcile
Separate current pages from old plans. Call out conflicting status statements, stale tasks, and milestones whose dates no longer match project reality.

## Output
Provide: Overall Status, Progress, Next Milestones, Blockers, Decisions Needed.

## Rule
Do not assume a task is unfinished because it lacks an update. Mark uncertain status rather than filling gaps.
