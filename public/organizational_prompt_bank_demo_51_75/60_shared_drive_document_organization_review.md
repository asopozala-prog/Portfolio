# 60 — Shared-drive document organization review

**Executor Type:** `Workplace AI`  
**Executor:** `Google Gemini`  
**Environment:** `Google Drive`  
**Department Tags:** `Operations`  
**Function Tags:** `Classification`, `Analysis`  
**Task:** `Shared-drive document organization review`

---

## Review Goal
Assess whether the shared Google Drive structure supports easy retrieval and version control.

## Inspect
Look for duplicate folders, vague names, mixed document types, inconsistent date naming, uncertain owners, outdated drafts, and multiple “final” versions.

## Organize
Suggest a small number of logical categories based on the actual contents, not a generic filing taxonomy.

## Output
Provide: Main Organization Problems, Proposed Structure, Naming Rules, Files Requiring Human Review.

## Constraint
Do not move, delete, rename, or merge files. Treat uncertain classifications as review items.
