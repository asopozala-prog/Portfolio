# 67 — Code documentation generation

**Executor Type:** `Coding / Technical AI`  
**Executor:** `GitHub Copilot`  
**Environment:** `IDE / Codebase`  
**Department Tags:** `Operations`  
**Function Tags:** `Analysis`, `Generation`, `Transformation`  
**Task:** `Code documentation generation`

---

## Task
Generate developer documentation for the selected code.

## Understand
Determine what the function, class, or module is responsible for, what it accepts, what it returns, dependencies, side effects, failure behavior, and important constraints.

## Explain
Document the contract and non-obvious behavior. Avoid narrating syntax line by line.

## Output
Write concise developer-facing documentation plus a short usage example if the code supports one.

## Verification
Do not describe behavior that the implementation does not provide. Flag unclear contracts instead of guessing.
